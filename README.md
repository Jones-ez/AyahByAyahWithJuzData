# AyahByAyahWithJuzData
Each Ayah in Chronological order, displaying the juz as a variable.

In the folder data/surah, the .json files are taken from the git respositary: https://github.com/semarketir/quranjson/tree/master

In the folder data/surah/arabicBySurahWithJuzData the ayahs are Juz marked.

Each arabicBySurahWithJuzData is in the json format:
(array)[
  (object){
    "juz": (integer),
    "surah": (integer),
    "ayah": (integer),
    "arabic": (string)
  }
]
